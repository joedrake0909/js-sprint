# Bill Splitter

## What it does
Calculates a tip, adds it to a bill, and splits the total among people.

## What I learned
- Variables store values used in calculations.
- A percentage is converted to a decimal by dividing by 100.
- JavaScript executes statements in order.
- `if/else` handles different conditions.
- Input validation prevents invalid calculations.
- Dividing a non-zero number by zero in JavaScript produces `Infinity`.

## Test results
- Bill: GH₵250
- Tip: 10% = GH₵25
- Total: GH₵275
- People: 4
- Per person: GH₵68.75
- Invalid input: 0 people produces an error message.

## How to run
`node bill-splitter/bill.js`
